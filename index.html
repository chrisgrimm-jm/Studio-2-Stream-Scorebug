⚾ Studio 2 Scorebug

Single-game OBS scorebug for supplement streams

Shows the score, inning, count, baserunners, and live at-bat/pitching info for one MLB game, meant to be docked at the bottom of a secondary stream watching just that game.

How it works
  1. Open the Control panel and enter a Unique ID for your stream
  2. Pick the game and a spoiler delay (how far behind live the bug should lag)
  3. Copy the generated OBS URL and add it as a Browser Source in OBS
  4. The bug updates itself as the game progresses — no further input needed
